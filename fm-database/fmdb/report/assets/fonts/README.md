Fonts for the body age report PDF, kept in the repo so a report renders the same with or without a network.

Caveat, Fraunces and Instrument Sans, latin and latin-ext subsets, as served by Google Fonts on 19 Nov 2026.
All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling.
`fonts.css` holds the @font-face rules; the report builder inlines each file into the page it prints.
